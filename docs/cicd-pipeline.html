Trivy gate

Scan runs on every build.

Report always uploaded to S3.

Docker Hub push only proceeds when TRIVY_SCAN_STATUS == 0.

Smoke test also gated on same condition.

Email rules

✅ Success — sent only on main branch or prod environment.

❌ Failure — sent on all environments, always.

Both include links to Trivy report, SonarCloud, and console output.
